Interpretation

The audit does not prove real-world discrimination, but it shows that a semantic matching model can change scores when qualifications stay fixed and only identity-coded text changes.

Experimental Setup

1

Create synthetic base resumes across software engineering, finance, marketing, healthcare, and education.

2

Generate counterfactual variants where only name, pronouns, or university changes.

3

Score every resume variant against every job description with Sentence-BERT cosine similarity.

4

Compare each variant score to the corresponding original resume score for the same job.

Current LLM Extension

The repo includes a prompt-based scorer using OpenAI's Responses API with gpt-5-mini. It returns a structured JSON match score and rationale for the same resume-job pairs.

Run Commands

1

export OPENAI_API_KEY=your_key_here

2

python ML_FINAL/scripts/run_llm_openai.py --limit 5

3

python ML_FINAL/scripts/run_llm_openai.py

4

python ML_FINAL/scripts/analyze_results.py --scores ML_FINAL/results/llm_scores.csv --score-col llm_score

Why Include It

Responds to the proposal feedback asking for a current LLM in addition to Sentence-BERT.
Uses the same counterfactual audit design, so results are comparable.
Keeps credentials out of the repo and makes LLM scoring optional for graders.
